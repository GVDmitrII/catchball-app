## Цель проекта
**Уровень 1:** Сайт Кипрской Федерации Catch'n Serve Ball — благотворительный, некоммерческий.

## SEO — полный аудит проведён, критичное и важное закрыто
### Закрыто
- vercel.json rewrite ("/(.*)"→"/index.html") — БЕЗ НЕГО 8 из 9 страниц отдавали настоящий 404 от сервера Vercel. Критический фикс.
- Per-route title/description/OG/Twitter Card — src/components/Seo.jsx, на всех 9 страницах, 3 языка (seo_title/seo_description в локалях)
- robots.txt (разрешает всех + явно GPTBot/ClaudeBot/PerplexityBot/Google-Extended)
- sitemap.xml (все 9 маршрутов, lastmod/changefreq/priority)
- JSON-LD: SportsOrganization (Home), NewsArticle (каждая новость), SportsEvent (события — events.json оказался с реальными данными)
- <html lang> синхронизирован с i18next (en/ru/el)
- Security-заголовки в vercel.json: X-Content-Type-Options, X-Frame-Options, Referrer-Policy
- IndexNow: ключ-файл public/{key}.txt + scripts/indexnow-submit.js — запускать ВРУЧНУЮ после публикации новой новости: `node scripts/indexnow-submit.js /news`
- llms.txt создан (public/llms.txt) — факто-ориентированная сводка для AI-краулеров

### Осознанно отложено / заблокировано
- SportsTeam JSON-LD для 5 клубов — ЗАБЛОКИРОВАНО: city/coach/schedule в clubs.json всё ещё "TBD". Добавить когда придут реальные данные.
- Favicon — ПРОПУЩЕН: нет реального квадратного файла логотипа. Сделать когда появится SVG/PNG лого.
- RU/GR контент не имеет отдельных URL (/ru/, /el/) и hreflang — один адрес на 3 языка через клиентский i18next означает, что Google физически не может проиндексировать русскую/греческую версию отдельно. Это ЗНАЧИМАЯ, но крупная задача (переделка роутинга) — сознательно отложена, не блокирует остальное.
- Полная очистка истории git (node_modules/dist раздувают .git) — низкий приоритет, требует filter-repo + force-push, НЕ делать без явного отдельного запроса.
- Core Web Vitals не измерены — можно сделать теперь, когда все страницы отдают 200.
